B.I.S Shop — نسخة الهاتف
1) ارفع المجلد إلى استضافة HTTPS (يمكن GitHub Pages أو أي استضافة ملفات ثابتة).
2) افتح index.html عبر رابط HTTPS من الهاتف.
3) من Chrome اختر "إضافة إلى الشاشة الرئيسية / Install app".
4) اسمح للكاميرا عند استعمال زر 📷.
5) البيانات محفوظة على الهاتف. استعمل النسخ الاحتياطي من الإعدادات.
ملاحظة: فتح index.html مباشرة من مدير الملفات قد يسمح بالتطبيق، لكن الكاميرا غالبًا لن تعمل؛ استخدم HTTPS للماسح.
